วิธีเพิ่มหนังสือเล่มใหม่

หนังสือหนึ่งเล่ม = โฟลเดอร์หนึ่งโฟลเดอร์ใน books/ ที่ข้างในมีไฟล์ HTML บทละไฟล์ แล้วลงทะเบียนไว้ในฐานข้อมูล books.html เท่านั้นเอง — ทั้ง repo นี้เป็นไฟล์ HTML ล้วน ไม่มี JSON ไม่มี build

ขั้นตอน

  1. สร้างโฟลเดอร์ใหม่ เช่น books/linear-algebra/
  2. ใส่ไฟล์บทเรียนเป็น HTML เช่น 01-vectors.html, 02-matrices.html
  3. เพิ่ม <section class="book"> ต่อท้ายใน books.html (ก่อนปิด </main>):
<section class="book" data-id="linear-algebra" data-cover="🧮">
  <h2>Linear Algebra สรุปจากคาบเรียน</h2>
  <p>สรุปเนื้อหาพีชคณิตเชิงเส้น เทอม 1/2569</p>
  <ol>
    <li><a href="books/linear-algebra/01-vectors.html">บทที่ 1 เวกเตอร์</a></li>
    <li><a href="books/linear-algebra/02-matrices.html">บทที่ 2 เมทริกซ์</a></li>
  </ol>
</section>

data-id ต้องตรงกับชื่อโฟลเดอร์ใน books/ และห้ามซ้ำกับเล่มอื่น เพราะใช้เก็บความคืบหน้าการอ่าน ส่วน data-cover เป็นอีโมจิอะไรก็ได้ ลำดับบทเรียงตามลำดับ <li>

เปิด books.html ตรง ๆ ก็ได้หน้ารายการหนังสือที่คลิกดูไฟล์ดิบแต่ละบทได้เลย — ฐานข้อมูลกับหน้าสารบัญรวมคือไฟล์เดียวกัน

รูปแบบไฟล์เนื้อหา

ไฟล์บทเรียนเป็นได้ 2 แบบ reader ดูจากนามสกุลไฟล์:

  • .md (แนะนำ) — markdown ธรรมดา เริ่มด้วย # ชื่อบท ใช้ตาราง code fence ได้หมด กล่องเน้นข้อความใช้ GitHub callout: > [!NOTE], > [!TIP], > [!WARNING] — ดูตัวอย่างที่บทถัดไป
  • .html — HTML fragment ไม่ต้องใส่ CSS/JavaScript เริ่มด้วย <h1> กล่องเน้นข้อความใช้ <div class="note">, <div class="tip">, <div class="warning">

ตัวอย่าง prompt สำหรับให้ AI สร้างบทเรียน

ช่วยสรุปเนื้อหาเรื่อง [หัวข้อ] จากไฟล์/โน้ตที่แนบมา แล้วเขียนเป็นไฟล์ HTML สำหรับ ebook ของฉัน โดยมีเงื่อนไข: เขียนเป็น HTML fragment ไม่ต้องมี CSS/JS, เริ่มด้วย <h1> ชื่อบท, แบ่งหัวข้อด้วย h2/h3, ใช้ <div class="note"> / <div class="tip"> / <div class="warning"> สำหรับจุดที่ควรเน้น, โค้ดใส่ใน <pre><code> แล้วบันทึกไฟล์ไว้ที่ books/[id]/[เลขลำดับ]-[ชื่อบท].html พร้อมเพิ่มลิงก์บทใน <section class="book"> ของหนังสือเล่มนั้นใน books.html ให้ด้วย

ถ้าใช้ Claude Code อยู่แล้ว แค่บอกว่า "เพิ่มบทใหม่เรื่อง X ในหนังสือ Y" มันจะอ่าน README ของ repo นี้แล้วทำให้ถูกรูปแบบเอง

วิธีเปิดอ่าน

เนื้อหาโหลดผ่าน fetch จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรง ๆ แบบ file:// ไม่ได้):

# รันในโฟลเดอร์ EbookMe
python3 -m http.server 8000

แล้วเปิด http://localhost:8000 — ถ้าอยากอ่านจากมือถือในบ้าน ให้เปิด http://[IP ของคอม]:8000 ผ่าน Wi-Fi วงเดียวกัน

ถ้าอยากอ่านจากที่ไหนก็ได้ push ขึ้น GitHub แล้วเปิด GitHub Pages (Settings → Pages → เลือก branch) เพราะทั้งเว็บเป็น static file ล้วน ๆ ใช้ได้ทันทีไม่ต้อง build
