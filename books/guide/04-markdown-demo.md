# เขียนบทเรียนด้วย Markdown

บทนี้ทั้งบทเป็นไฟล์ `.md` — reader อ่าน markdown ได้โดยตรงแล้ว ได้ไฟล์จาก AI มาก็โยนลง `books/<id>/` แล้วเพิ่มลิงก์ใน `books.html` ได้เลย **ไม่ต้องแปลงเป็น HTML ก่อน**

## วิธีเพิ่มบทที่เป็น markdown

1. เซฟไฟล์เป็น `books/<id>/<เลขลำดับ>-<ชื่อบท>.md`
2. เพิ่มลิงก์ใน `books.html` เหมือนบท HTML ทุกประการ แค่ href ชี้ไปที่ไฟล์ `.md`:

```html
<li><a href="books/guide/04-markdown-demo.md">เขียนบทเรียนด้วย Markdown</a></li>
```

## สิ่งที่รองรับ

**ตัวหนา** *ตัวเอียง* `โค้ดในบรรทัด` และ[ลิงก์](https://www.markdownguide.org/) — ครบตามมาตรฐาน markdown

- ลิสต์แบบไม่เรียงลำดับ
  - ซ้อนกันได้
- ตารางก็ได้:

| เขียนใน HTML | เขียนใน Markdown |
|---|---|
| `<h2>หัวข้อ</h2>` | `## หัวข้อ` |
| `<strong>หนา</strong>` | `**หนา**` |
| `<pre><code>...</code></pre>` | ` ```โค้ด``` ` |

```python
def hello():
    print("สวัสดี markdown!")  # โค้ดบล็อกพร้อมภาษากำกับ
```

> blockquote ธรรมดา ยังคงเป็น blockquote เหมือนเดิม
