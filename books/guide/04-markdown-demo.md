# เขียนบทเรียนด้วย Markdown

บทนี้ทั้งบทเป็นไฟล์ `.md` — reader อ่าน markdown ได้โดยตรงแล้ว ได้ไฟล์จาก AI มาก็โยนลง `books/<id>/` แล้วเพิ่มลิงก์ใน `books.html` ได้เลย **ไม่ต้องแปลงเป็น HTML ก่อน**

## วิธีเพิ่มบทที่เป็น markdown

1. เซฟไฟล์เป็น `books/<id>/<เลขลำดับ>-<ชื่อบท>.md`
2. เพิ่มลิงก์ใน `books.html` เหมือนบท HTML ทุกประการ แค่ href ชี้ไปที่ไฟล์ `.md`:

```html
<li><a href="books/guide/04-markdown-demo.md">เขียนบทเรียนด้วย Markdown</a></li>
```

## สิ่งที่รองรับ

**ตัวหนา** *ตัวเอียง* `โค้ดในบรรทัด` และ[ลิงก์](https://www.markdownguide.org/) — ครบตามมาตรฐาน markdown

- ลิสต์แบบไม่เรียงลำดับ
  - ซ้อนกันได้
- ตารางก็ได้:

| เขียนใน HTML | เขียนใน Markdown |
|---|---|
| `<h2>หัวข้อ</h2>` | `## หัวข้อ` |
| `<strong>หนา</strong>` | `**หนา**` |
| `<pre><code>...</code></pre>` | ` ```โค้ด``` ` |

```python
def hello():
    print("สวัสดี markdown!")  # โค้ดบล็อกพร้อมภาษากำกับ
```

> blockquote ธรรมดา ยังคงเป็น blockquote เหมือนเดิม

> [!TIP]

## สีโค้ดอัตโนมัติ (syntax highlighting)

โค้ดบล็อกที่กำกับภาษาไว้จะถูกลงสีให้อัตโนมัติ และสีจะเปลี่ยนตามธีมของเว็บด้วย:

```javascript
async function loadBook(id) {
  const res = await fetch(`api/books?id=${id}`); // ดึงสารบัญ
  if (!res.ok) throw new Error('โหลดไม่สำเร็จ');
  return res.json();
}
```

## สูตรคณิตศาสตร์ (KaTeX)

เขียนแบบ inline ในประโยคได้ เช่น พีทาโกรัส $a^2 + b^2 = c^2$ หรือเศษส่วน $\frac{1}{n}$
และเขียนแบบแยกบรรทัดด้วย `$$...$$`:

$$
\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

รูปแบบ `\(...\)` กับ `\[...\]` ก็ใช้ได้เหมือนกัน ส่วนเครื่องหมาย $ ในโค้ดหรือราคาเงิน เช่น $5 จะไม่ถูกตีความเป็นสูตร

## แผนภาพ mermaid

ใส่ code fence ภาษา `mermaid` แล้วระบบจะวาดเป็นแผนภาพให้ (สีตามธีมของเว็บ):

```mermaid
flowchart LR
  A[ให้ AI สรุปเนื้อหา] --> B[ได้ไฟล์ .md]
  B --> C{อัปโหลดที่หน้า ＋}
  C -->|เล่มใหม่| D[สร้างหนังสือ]
  C -->|เล่มเดิม| E[เพิ่มบท]
  D --> F[เปิดอ่านได้ทุกเครื่อง]
  E --> F
```

## รูปภาพ

แปะลิงก์รูปแบบเต็ม (https://...) ได้เลย หรืออัปโหลดรูปขึ้นคลาวด์จากหน้าอัปโหลด (ปุ่ม 🖼️ รูปประกอบ) แล้วระบบจะแทรกลิงก์ให้:

```markdown
![คำอธิบายรูป](https://example.com/diagram.png)
```
