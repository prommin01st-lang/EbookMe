# 📚 EbookMe

เว็บอ่าน ebook ส่วนตัวแบบ static — เอาเนื้อหาที่เรียนมาให้ AI แปลงเป็น HTML แล้ววางในโฟลเดอร์ `books/` ก็อ่านได้ทันทีทั้งบนคอม มือถือ และแท็บเล็ต **ทั้ง repo เป็นไฟล์ HTML ล้วน** ไม่มี JSON ไม่ต้อง build ไม่ต้องติดตั้งอะไร

## วิธีเปิดอ่าน

เนื้อหาโหลดผ่าน `fetch` จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิด file:// ตรง ๆ ไม่ได้):

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

- **อ่านจากมือถือในบ้าน:** เปิด `http://<IP ของคอม>:8000` ผ่าน Wi-Fi วงเดียวกัน
- **อ่านจากทุกที่ (Vercel):** push ขึ้น GitHub → import โปรเจกต์ที่ [vercel.com](https://vercel.com) (Framework Preset: Other, ไม่ต้องตั้ง build อะไร) → ได้ URL ถาวร และทุกครั้งที่ push เนื้อหาใหม่ Vercel จะ deploy ให้อัตโนมัติ
- GitHub Pages ก็ใช้ได้เหมือนกัน (Settings → Pages) เพราะเป็น static ล้วน

## โครงสร้าง

```
index.html          ← หน้าชั้นหนังสือ (รวมหนังสือใน repo + หนังสือบนคลาวด์) + ค้นหาข้ามเล่ม
reader.html         ← หน้าอ่าน (สารบัญ, ปรับฟอนต์, ธีม, จำตำแหน่งอ่าน)
books.html          ← ฐานข้อมูลหนังสือใน repo (HTML — เปิดดูตรง ๆ ก็เป็นหน้ารายการหนังสือ)
upload.html         ← หน้าอัปโหลดหนังสือ/รูปขึ้นคลาวด์ (ใช้ได้เมื่ออยู่บน Vercel)
api/books.js        ← serverless function: สารบัญ/อัปโหลด/แก้ไข/ลบ หนังสือบน Vercel Blob
api/images.js       ← serverless function: อัปโหลดรูปประกอบขึ้น Blob
sw.js + manifest.webmanifest ← PWA: ติดตั้งบนมือถือได้ + อ่านบทที่เคยเปิดแบบออฟไลน์
assets/app.css      ← สไตล์ทั้งหมด
assets/catalog.js   ← รวมฐานข้อมูล 2 แหล่ง: books.html + /api/books
assets/marked.min.js ← markdown parser (ใช้ตอนเปิดบทที่เป็น .md)
assets/highlight.min.js ← สีโค้ด (โหลดเฉพาะบทที่มี code block)
assets/katex/*      ← สูตรคณิต (โหลดเฉพาะบทที่มีสูตร)
assets/mermaid.min.js ← แผนภาพ mermaid (โหลดเฉพาะบทที่มีแผนภาพ)
books/<id>/*        ← เนื้อหาบทเรียน บทละไฟล์ (.html หรือ .md)
```

## วิธีเพิ่มหนังสือ (สำหรับ AI: ทำตามนี้เป๊ะ ๆ)

1. สร้างโฟลเดอร์ `books/<id>/` (id เป็น kebab-case ภาษาอังกฤษ ห้ามซ้ำ)
2. สร้างไฟล์บทเรียนชื่อ `<เลขสองหลัก>-<slug>.html` เช่น `01-vectors.html`
3. เพิ่ม `<section class="book">` ต่อท้ายใน `books.html` (ก่อนปิด `</main>`):

```html
<section class="book" data-id="linear-algebra" data-cover="🧮">
  <h2>Linear Algebra สรุปจากคาบเรียน</h2>
  <p>คำอธิบายสั้น ๆ หนึ่งประโยค</p>
  <ol>
    <li><a href="books/linear-algebra/01-vectors.html">บทที่ 1 เวกเตอร์</a></li>
  </ol>
</section>
```

กติกาที่ parser (`assets/catalog.js`) ใช้อ่าน:

- `data-id` = ชื่อโฟลเดอร์ใน `books/` (ใช้เก็บความคืบหน้าการอ่าน — ห้ามซ้ำ ห้ามเปลี่ยนทีหลัง)
- `data-cover` = อีโมจิหน้าปกหนึ่งตัว
- `<h2>` = ชื่อหนังสือ, `<p>` แรก = คำอธิบาย
- ลิงก์บทอยู่ใน `<li><a href="books/<id>/<ไฟล์>.html">ชื่อบท</a></li>` เรียงตามลำดับ

### กติกาของไฟล์เนื้อหา

ไฟล์บทเรียนเป็นได้ 2 แบบ (ดูจากนามสกุลไฟล์):

**แบบ `.md` (แนะนำ — AI ส่วนใหญ่คายออกมาเป็นแบบนี้อยู่แล้ว)**

- markdown มาตรฐานทั้งหมด: หัวข้อ, ลิสต์, ตาราง, code fence, blockquote, ลิงก์, รูป
- กล่องเน้นข้อความใช้ GitHub callout: `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]` (`[!IMPORTANT]` = note, `[!CAUTION]` = warning)
- code fence กำกับภาษา (` ```python `) จะถูกลงสีอัตโนมัติ
- สูตรคณิต: `$inline$`, `$$display$$`, `\( \)`, `\[ \]` — render ด้วย KaTeX
- แผนภาพ: code fence ภาษา ` ```mermaid ` จะถูกวาดเป็นแผนภาพ (สีตามธีม)
- รูปภาพ: ใช้ลิงก์แบบเต็ม `![คำอธิบาย](https://...)` เท่านั้น (ลิงก์ relative จะพังตอนอ่านผ่าน reader)
- **ลิงก์ข้ามบทในเล่มเดียวกัน: ใช้ชื่อไฟล์ตรง ๆ ได้เลย** เช่น `[บทที่ 5](05-attention.md)` — reader จะพาไปเปิดบทนั้นให้เอง จึงทำ**ไฟล์สารบัญ** (เช่น `00-index.md` ที่มีตารางลิงก์ทุกบท) เป็นบทแรกของเล่มได้
- เริ่มบทด้วย `# ชื่อบท` หนึ่งอัน

**แบบ `.html`**

- เป็น **HTML fragment** — ไม่ต้องมี `<html>`, `<head>`, CSS, หรือ JavaScript ใด ๆ (reader จัดสไตล์ให้เองทั้งหมด และจะดึงเฉพาะเนื้อหาใน body ถ้าเผลอใส่มาเต็มไฟล์)
- ถ้าไฟล์แอบพก `<style>`, `style="…"`, `<script>`, `<font>`, `bgcolor` มาด้วย reader จะ **ล้างออกทั้งหมด** ตอนแสดงผล เพื่อให้สีตามธีมของเว็บเสมอ
- เริ่มบทด้วย `<h1>` หนึ่งอัน แบ่งหัวข้อด้วย `<h2>` / `<h3>`
- กล่องเน้นข้อความ: `<div class="note">`, `<div class="tip">`, `<div class="warning">`

ดูตัวอย่างครบทุกองค์ประกอบได้ที่ `books/guide/03-showcase.html` (HTML) และ `books/guide/04-markdown-demo.md` (markdown)

## อัปโหลดขึ้นคลาวด์ (ไม่ต้องผ่าน git)

เมื่อ deploy บน Vercel แล้ว กดปุ่ม **＋** บนชั้นหนังสือจะเข้าหน้า `upload.html` — เลือกไฟล์ .md/.html หรือวางเนื้อหา แล้วอัปโหลดเก็บใน **Vercel Blob** ได้จากทุกอุปกรณ์ หนังสือที่อัปโหลดจะขึ้นบนชั้นพร้อมป้าย ☁️ อ่านได้เหมือนหนังสือใน repo ทุกอย่าง

**ตั้งค่าครั้งแรก (ใน dashboard ของ Vercel):**

1. Storage → Create Database → **Blob** → เชื่อมกับโปรเจกต์นี้ (จะได้ env `BLOB_READ_WRITE_TOKEN` อัตโนมัติ)
2. Settings → Environment Variables → เพิ่ม `UPLOAD_KEY` = รหัสลับที่ตั้งเอง (ใครมี key นี้ = อัปโหลด/ลบได้)
3. Redeploy หนึ่งครั้ง

**การทำงาน:**

- อ่าน = สาธารณะ (ใครมีลิงก์ก็อ่านได้) / เขียน+ลบ = ต้องแนบ key (`Authorization: Bearer <UPLOAD_KEY>`)
- ใส่ key ครั้งแรกครั้งเดียวในหน้าอัปโหลด เบราว์เซอร์จะจำไว้ (localStorage ผูกกับโดเมนของเว็บ)
- เลือกไฟล์ .md **หลายไฟล์พร้อมกันได้** — ไฟล์ละบท เรียงตามชื่อไฟล์ หรือไฟล์เดียวแบ่งเป็นหลายบทตามหัวข้อ #/## ก็ได้
- แนบ**รูปประกอบ**ได้จากขั้นใส่เนื้อหา (ไม่เกิน 3MB/รูป) — อัปขึ้น Blob แล้วแทรกลิงก์ markdown ให้เอง
- **แก้ไขทีหลังได้**: ชื่อเล่ม/คำอธิบาย/ปกอีโมจิ/ชื่อบท จากปุ่ม ✏️ ในขั้นเลือกหนังสือ
- สารบัญคลาวด์เก็บเป็น JSON ใน Blob (เขียนแบบ versioned), เนื้อหาบทเก็บเป็นไฟล์ .md/.html ใน Blob
- API: `GET /api/books` (สารบัญ), `POST /api/books` (อัปโหลด/แก้บท), `PATCH /api/books` (แก้ข้อมูลเล่ม/ชื่อบท), `DELETE /api/books?bookId=..&file=..` (ลบบท ถ้าไม่ส่ง file = ลบทั้งเล่ม), `POST /api/images` (อัปโหลดรูป `{filename, dataBase64}`)

## ฟีเจอร์ของ reader

- ธีมสว่าง / ซีเปีย / มืด (ค่าเริ่มต้นตามระบบ)
- ปรับขนาดตัวอักษร 14–26px
- 🔍 ค้นหาข้อความข้ามทุกเล่มจากหน้าชั้นหนังสือ — กดผลค้นหาแล้วเปิดบทนั้นพร้อมไฮไลต์คำที่เจอ
- สีโค้ด (highlight.js), สูตรคณิต (KaTeX), แผนภาพ (mermaid) — โหลดเฉพาะบทที่ใช้จริง
- PWA: Add to Home Screen บนมือถือได้ และบท/หน้าที่เคยเปิดแล้วอ่านซ้ำได้แม้ออฟไลน์
- จำตำแหน่งอ่านล่าสุดของแต่ละบท + ปุ่ม "อ่านต่อ" ที่หน้าชั้นหนังสือ
- นับบทที่อ่านจบ (เลื่อนถึง 90%) แสดง ✓ ในสารบัญและ progress bar ที่หน้าชั้นหนังสือ
- ปุ่ม prev/next, สารบัญแบบ drawer, ลูกศร ← → บนคีย์บอร์ด
- ตารางกว้างเลื่อนแนวนอนในกรอบตัวเอง, รองรับ safe-area ของมือถือมีติ่ง

ข้อมูลการอ่านทั้งหมดเก็บใน localStorage ของแต่ละอุปกรณ์ ไม่มี backend
