# 📚 EbookMe

เว็บอ่าน ebook ส่วนตัวแบบ static — เอาเนื้อหาที่เรียนมาให้ AI แปลงเป็น HTML แล้ววางในโฟลเดอร์ `books/` ก็อ่านได้ทันทีทั้งบนคอม มือถือ และแท็บเล็ต **ทั้ง repo เป็นไฟล์ HTML ล้วน** ไม่มี JSON ไม่ต้อง build ไม่ต้องติดตั้งอะไร

## วิธีเปิดอ่าน

เนื้อหาโหลดผ่าน `fetch` จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิด file:// ตรง ๆ ไม่ได้):

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

- **อ่านจากมือถือในบ้าน:** เปิด `http://<IP ของคอม>:8000` ผ่าน Wi-Fi วงเดียวกัน
- **อ่านจากทุกที่ (Vercel):** push ขึ้น GitHub → import โปรเจกต์ที่ [vercel.com](https://vercel.com) (Framework Preset: Other, ไม่ต้องตั้ง build อะไร) → ได้ URL ถาวร และทุกครั้งที่ push เนื้อหาใหม่ Vercel จะ deploy ให้อัตโนมัติ
- GitHub Pages ก็ใช้ได้เหมือนกัน (Settings → Pages) เพราะเป็น static ล้วน

## โครงสร้าง

```
index.html          ← หน้าแรก: ชั้นหนังสือ 3D (WebGL) + มุมมองตาราง + ค้นหาข้ามเล่ม
reader.html         ← หน้าอ่าน (สารบัญ, ปรับฟอนต์, ธีม, จำตำแหน่งอ่าน)
books.html          ← ฐานข้อมูลหนังสือใน repo (HTML — เปิดดูตรง ๆ ก็เป็นหน้ารายการหนังสือ)
upload.html         ← หน้าอัปโหลดหนังสือ/รูปขึ้นคลาวด์ (ใช้ได้เมื่ออยู่บน Vercel)
api/books.js        ← serverless function: สารบัญ/อัปโหลด/แก้ไข/ลบ หนังสือบน Vercel Blob
api/images.js       ← serverless function: อัปโหลดรูปประกอบขึ้น Blob
sw.js + manifest.webmanifest ← PWA: ติดตั้งบนมือถือได้ + อ่านบทที่เคยเปิดแบบออฟไลน์
assets/app.css      ← สไตล์ทั้งหมด (topbar, การ์ดหนังสือ, ค้นหา, หน้าอ่าน)
assets/shelf.css    ← สไตล์เฉพาะชั้นหนังสือ 3D บนหน้าแรก
assets/shelf.js     ← ฉาก 3D: สร้างเล่ม ปก สัน หน้ากระดาษ แสง และการพลิกหน้า
assets/three/*      ← three.js r165 + addons (ตรึงเวอร์ชัน ไม่พึ่ง CDN จึงออฟไลน์ได้)
assets/catalog.js   ← รวมฐานข้อมูล 2 แหล่ง: books.html + /api/books
assets/marked.min.js ← markdown parser (ใช้ตอนเปิดบทที่เป็น .md)
assets/highlight.min.js ← สีโค้ด (โหลดเฉพาะบทที่มี code block)
assets/katex/*      ← สูตรคณิต (โหลดเฉพาะบทที่มีสูตร)
assets/mermaid.min.js ← แผนภาพ mermaid (โหลดเฉพาะบทที่มีแผนภาพ)
books/<id>/*        ← เนื้อหาบทเรียน บทละไฟล์ (.html หรือ .md)
```

## หน้าแรก — ชั้นหนังสือ 3D

หน้าตา fork มาจาก [The Complete Shelf](https://github.com/MengTo/complete-shelf) ของ MengTo
ซึ่งเปิดให้ remix ผ่าน `PROMPT.md` ของเขา สิ่งที่ต่างจากต้นฉบับ:

- **หนังสือมาจาก catalog จริง** ไม่ใช่ 7 เล่มตายตัว — เพิ่ม/ลบหนังสือแล้วชั้นเปลี่ยนตามทันที
- **ปก สัน ปกหลัง และหน้าในวาดสดด้วย canvas** ต้นฉบับฝังภาพปกมาเป็น WebP atlas ซึ่งใช้กับ
  หนังสือที่เปลี่ยนไปเรื่อย ๆ ไม่ได้ ลายไม้ของชั้นก็สร้างจาก noise แทนภาพฝัง
- **รองรับภาษาไทย** ตัดบรรทัดด้วย `Intl.Segmenter` และย่อขนาดตัวอักษรให้พอดีปก
  (ต้นฉบับตัดคำที่ช่องว่าง ซึ่งภาษาไทยไม่มี)
- **เนื้อหาข้างในเป็นของจริง** — พลิกดูได้เป็นสารบัญ ความคืบหน้าการอ่าน และบทที่ค้างไว้
- ผ้าหุ้มปกเลือกจาก hash ของ `id` หนังสือ เล่มเดิมจึงได้สีเดิมเสมอ และเล่มหนาตามจำนวนบท

ปุ่ม **ตาราง** สลับไปมุมมองการ์ดแบบเดิม (มีฟิลเตอร์/สถิติ/ค้นหา) และจำไว้ใน `localStorage`
เครื่องที่ไม่มี WebGL จะตกมาที่มุมมองตารางเองอัตโนมัติ ตอนอยู่มุมมองตารางฉาก 3D จะหยุดวาด
เพื่อไม่ให้กินแบตฟรี ๆ

### อ่านแบบ 3D กับ 2D

กด **อ่านแบบ 3D** ในแผงรายละเอียดแล้วหนังสือจะกางออกพร้อมเนื้อหาจริงของบทที่ค้างไว้
พลิกได้ด้วยการลากหน้ากระดาษ ปุ่มลูกศร หรือปุ่มบทก่อนหน้า/ถัดไป
ในหน้าอ่าน 2D มีปุ่ม **📕 3D** พาบทเดียวกันไปเปิดในหนังสือ และแผงรายละเอียดมีปุ่ม
**อ่านแบบ 2D** พากลับมา ทั้งสองทางจำไว้ว่าครั้งล่าสุดอ่านแบบไหน

การจัดหน้าปรับตามอุปกรณ์เอง:

| สถานการณ์ | สิ่งที่เห็น |
| --- | --- |
| จอกว้างแนวนอน — แค่หยิบมาดู | สองหน้าคู่ + แผงรายละเอียดด้านข้าง |
| กำลังอ่าน (ทุกขนาดจอ) | แผงยุบเหลือปุ่มลอยเล็ก ๆ กลางล่างจอ (`✕ ‹ หน้า x/y › ⌃`) ปุ่มลูกศรมีสองสถานะเท่านั้น กาง ↔ ย่อ ไม่ใช่วนหลายระดับ |
| แผงข้าง (จอกว้างแนวนอน) | กดย่อได้เหมือนกัน — แผงจะย้ายลงไปเป็นแถบล่างจอ หนังสือได้เต็มจอจริง ไม่ใช่แค่ไอคอนเปลี่ยน |
| แนวตั้ง (ทุกขนาดจอ) | อ่านทีละหน้า — สเปรดสองหน้าบนจอแนวตั้งเสียความสูงไปครึ่งจอเสมอ |
| แนวตั้ง (ทุกความกว้าง) | แผงรายละเอียดเป็นแผ่นล่างจอที่หุบได้ กล้องวัดขนาดเล่มแล้วจัดกรอบให้พอดี |
| แท็บเล็ตแนวตั้ง | สองหน้าคู่ ย่อพอดีทั้งสเปรด |
| มือถือแนวตั้ง (<720px) | อ่านทีละหน้าเต็มจอ พลิกหนึ่งครั้ง = เดินหนึ่งหน้า (ขวา → ซ้ายของสเปรดถัดไป → ขวา) ไม่ข้ามเนื้อหา กล้องไถลตามแบบ ease-out |
| มือถือแนวนอน (สูง ≤480px) | แถบบน-ล่างบีบให้เตี้ย ซ่อนคำอธิบายที่ไม่จำเป็น |
| นิ้วสัมผัส | ปุ่มทุกปุ่มขยายเป็น 44px และปัดนิ้วเลื่อนชั้นหนังสือได้ |
| สั่งเองก็ได้ | ปุ่ม **▭▭ หน้าคู่ / ▭ หน้าเดียว** ทับค่าอัตโนมัติ และจำไว้ |
| ไม่มี WebGL / จอเล็กกว่า 320px / ตั้งลดการเคลื่อนไหว | เด้งไปหน้าอ่าน 2D ให้เลย |

ในแผงรายละเอียด (ตอนกางเต็ม) มีสองแถวที่คุมการอ่านโดยตรง:

- **สารบัญแบบเลือกบท** — ดรอปดาวน์รายชื่อบททั้งเล่ม เลือกบทไหนก็กระโดดไปได้ทันที
  ไม่ต้องกด "บทถัดไป" ทีละบท ถ้ายังไม่ได้เปิดอ่านก็ถือว่าเลือกบทแล้วเปิดเล่มไปที่บทนั้นเลย
- **A− / A+** — ปรับขนาดตัวอักษร 14–26 ใช้ค่าเดียวกับหน้าอ่าน 2D (`ebook:fontSize`)
  ตั้งที่ไหนก็มีผลอีกที่ ขนาดเปลี่ยน = จำนวนบรรทัดต่อหน้าเปลี่ยน ระบบจึงจัดหน้าใหม่ทั้งบท
  แล้วพากลับไปที่ตำแหน่งเดิมโดยเทียบสัดส่วน (อ่านมาถึง 30% ของบท ก็ยังอยู่ที่ 30%)
  ตารางที่คอลัมน์เริ่มแคบเกินคำจะย่อขนาดเฉพาะตารางนั้นลงเอง ข้อความจึงไม่ล้นทับคอลัมน์ข้าง ๆ

ธีม (สว่าง / ซีเปีย / มืด) มีผลกับหนังสือ 3D ด้วย ไม่ใช่แค่มุมมองตาราง — สีกระดาษ
สีหมึก ความสว่างของห้อง และสีตัวอักษรบนแผงควบคุมเปลี่ยนตามทั้งชุด กระดาษถูกวาดใหม่
ทุกครั้งที่สลับธีมเพราะตัวหนังสือถูกอบเป็นภาพไว้แล้ว

**ปุ่มไหนทำอะไร:** ปุ่มหลักในแผงคือ **เริ่มอ่าน / อ่านต่อ บทที่ N** ซึ่งกางหนังสือตรงนั้นเลย
ไม่พาไปหน้าอื่น ส่วนการย้ายไปหน้าอ่าน 2D อยู่ในแท็บคู่ **📕 หนังสือ 3D / 📄 หน้าอ่าน 2D**
ที่บอกว่ากำลังอ่านอยู่แบบไหน ทั้งสองหน้าจัดลำดับปุ่มท้ายแถบเหมือนกัน คือ
*ปุ่มสลับมุมมอง* แล้วปิดท้ายด้วย *ปุ่มธีม* เสมอ

### เรื่องประสิทธิภาพบนมือถือ

ฉาก 3D ถูกปรับให้ไม่กินเครื่องเกินจำเป็น:

- **หยุดวาดเมื่อไม่มีอะไรขยับ** — ต้นฉบับวาด 60fps ตลอดเวลาเพราะมีหนังสือลอยขยับกับฝุ่น
  ในอากาศ บนมือถือคือ GPU ทำงานเต็มที่ทั้งวัน เครื่องร้อนแล้วโดนหรี่ความเร็ว (ที่เรารู้สึกว่า
  "กระตุก") ตอนนี้หนังสือบนชั้นลอยขยับเฉพาะ 9 วินาทีหลังแตะจอครั้งล่าสุด และตอนอ่านที่ฉาก
  นิ่งสนิทจะไม่วาดเลยแม้แต่เฟรมเดียว
- **ภาพที่มองไม่เห็นจะไม่ถูกสร้าง** — ปกหลัง ใบรองปก และหน้าในถูกสร้างตอนหยิบเล่มนั้นออกมาดู
  เท่านั้น เดิมสร้างล่วงหน้าทุกเล่มกินหน่วยความจำ GPU เล่มละ ~25MB ทั้งที่ยืนอยู่บนชั้นไม่มีวันเห็น
- **ชั้นหนังสือถูกซ่อนตอนอ่าน** เล่มที่หยิบออกมาถูกย้ายออกจากชั้นแล้ว ที่เหลือไม่มีใครเห็น
- **เงาวาดใหม่เฉพาะตอนวัตถุขยับ** กล้องไถลอย่างเดียวไม่ต้องคำนวณเงาใหม่
- **โปรไฟล์เครื่อง** จอสัมผัส/จอแคบได้เท็กซ์เจอร์ครึ่งความละเอียด, anisotropy 4 แทน 16,
  shadow map 1024 แทน 2048, ไฟเสริมเหลือเท่าที่จำเป็น และปิด MSAA

### อะไรบ้างที่แสดงในหนังสือ 3D

หน้ากระดาษวาดตามชนิดของเนื้อหา ไม่ใช่แปลงทุกอย่างเป็นย่อหน้าเหมือนกันหมด:

| เนื้อหา | ในหนังสือ 3D |
| --- | --- |
| หัวข้อ h1–h3 | ตัวหนา ขนาดลดหลั่น มีระยะห่างก่อน/หลัง |
| ตัวหนา / ตัวเอียง / `โค้ดในบรรทัด` | เห็นต่างกันจริง (ฟอนต์คนละแบบ) |
| ลิสต์ (มี/ไม่มีลำดับ ซ้อนชั้นได้) | จุดหรือเลขนำ พร้อมย่อหน้าตรงกัน |
| ตาราง | ตารางจริง มีหัวตารางเน้นสี แถวสลับ และเส้นคั่น |
| โค้ดบล็อก | ตัวอักษร monospace ในกรอบสีอ่อน ยาวข้ามหน้าได้กรอบยังต่อเนื่อง |
| blockquote / callout `[!NOTE]` `[!WARNING]` | กล่องมีแถบซ้าย พร้อมป้ายชนิดเป็นภาษาไทย |
| เส้นคั่น `---` | เส้นคั่นกลางหน้า |
| รูปภาพ | วาดลงหน้ากระดาษจริง |
| แผนภาพ mermaid | วาดจริง และขยายให้อ่านออกได้เพราะเป็น SVG |
| สูตรคณิต | แสดงเป็นซอร์ส LaTeX ตัวเอียง monospace (ยังไม่ typeset) |

**การตัดหน้าไม่ผ่ากลางของที่ต้องอยู่ด้วยกัน:** หัวตารางต้องมีแถวข้อมูลตามมาอย่างน้อยหนึ่งแถว
หัวข้อต้องมีเนื้อหาตามมา จุดนำลิสต์ต้องอยู่กับข้อความของข้อนั้น และย่อหน้าจะไม่ทิ้งบรรทัดเดียว
ไว้ท้ายหน้าหรือส่งบรรทัดเดียวไปโดดหน้าใหม่ ถ้าจุดตัดผิดกฎ ระบบจะเลื่อนจุดตัดขึ้นมาให้
ส่วนตารางที่ยาวข้ามหน้า หน้าถัดไปจะมีหัวตารางซ้ำให้

**ข้อจำกัดของโหมด 3D ที่ควรรู้:** ตัวหนังสือถูกวาดเป็นภาพลงกระดาษ จึงเลือก คัดลอก
หรือค้นหาข้อความไม่ได้ และโค้ด สูตรคณิต กับแผนภาพ mermaid จะไม่ถูกวาด —
สูตรคณิตยังไม่ถูก typeset (KaTeX วาดด้วย HTML+CSS ซึ่ง rasterize ลง canvas ไม่ได้)
และรูปข้ามโดเมนที่เซิร์ฟเวอร์ไม่ส่งหัว CORS จะขึ้นเป็นกล่องหมายเหตุแทน เพราะ WebGL
ปฏิเสธเท็กซ์เจอร์ที่วาดจากภาพซึ่งทำให้ canvas เปื้อน ผลคือทั้งหน้าจะว่าง ไม่ใช่แค่รูปหาย
หนังสือมีกระดาษจริง 4 ใบ (8 หน้า) เนื้อหาที่ยาวกว่านั้นจะถูกแบ่งเป็นชุดละ 8 หน้า
ตอนข้ามชุดภาพบนกระดาษจะเปลี่ยนทีเดียวแทนการพลิก

## วิธีเพิ่มหนังสือ (สำหรับ AI: ทำตามนี้เป๊ะ ๆ)

1. สร้างโฟลเดอร์ `books/<id>/` (id เป็น kebab-case ภาษาอังกฤษ ห้ามซ้ำ)
2. สร้างไฟล์บทเรียนชื่อ `<เลขสองหลัก>-<slug>.html` เช่น `01-vectors.html`
3. เพิ่ม `<section class="book">` ต่อท้ายใน `books.html` (ก่อนปิด `</main>`):

```html
<section class="book" data-id="linear-algebra" data-cover="🧮">
  <h2>Linear Algebra สรุปจากคาบเรียน</h2>
  <p>คำอธิบายสั้น ๆ หนึ่งประโยค</p>
  <ol>
    <li><a href="books/linear-algebra/01-vectors.html">บทที่ 1 เวกเตอร์</a></li>
  </ol>
</section>
```

กติกาที่ parser (`assets/catalog.js`) ใช้อ่าน:

- `data-id` = ชื่อโฟลเดอร์ใน `books/` (ใช้เก็บความคืบหน้าการอ่าน — ห้ามซ้ำ ห้ามเปลี่ยนทีหลัง)
- `data-cover` = อีโมจิหน้าปกหนึ่งตัว
- `<h2>` = ชื่อหนังสือ, `<p>` แรก = คำอธิบาย
- ลิงก์บทอยู่ใน `<li><a href="books/<id>/<ไฟล์>.html">ชื่อบท</a></li>` เรียงตามลำดับ

### กติกาของไฟล์เนื้อหา

ไฟล์บทเรียนเป็นได้ 2 แบบ (ดูจากนามสกุลไฟล์):

**แบบ `.md` (แนะนำ — AI ส่วนใหญ่คายออกมาเป็นแบบนี้อยู่แล้ว)**

- markdown มาตรฐานทั้งหมด: หัวข้อ, ลิสต์, ตาราง, code fence, blockquote, ลิงก์, รูป
- กล่องเน้นข้อความใช้ GitHub callout: `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]` (`[!IMPORTANT]` = note, `[!CAUTION]` = warning)
- code fence กำกับภาษา (` ```python `) จะถูกลงสีอัตโนมัติ
- สูตรคณิต: `$inline$`, `$$display$$`, `\( \)`, `\[ \]` — render ด้วย KaTeX
- แผนภาพ: code fence ภาษา ` ```mermaid ` จะถูกวาดเป็นแผนภาพ (สีตามธีม)
- รูปภาพ: ใช้ลิงก์แบบเต็ม `![คำอธิบาย](https://...)` เท่านั้น (ลิงก์ relative จะพังตอนอ่านผ่าน reader)
- **ลิงก์ข้ามบทในเล่มเดียวกัน: ใช้ชื่อไฟล์ตรง ๆ ได้เลย** เช่น `[บทที่ 5](05-attention.md)` — reader จะพาไปเปิดบทนั้นให้เอง จึงทำ**ไฟล์สารบัญ** (เช่น `00-index.md` ที่มีตารางลิงก์ทุกบท) เป็นบทแรกของเล่มได้
- เริ่มบทด้วย `# ชื่อบท` หนึ่งอัน

**แบบ `.html`**

- เป็น **HTML fragment** — ไม่ต้องมี `<html>`, `<head>`, CSS, หรือ JavaScript ใด ๆ (reader จัดสไตล์ให้เองทั้งหมด และจะดึงเฉพาะเนื้อหาใน body ถ้าเผลอใส่มาเต็มไฟล์)
- ถ้าไฟล์แอบพก `<style>`, `style="…"`, `<script>`, `<font>`, `bgcolor` มาด้วย reader จะ **ล้างออกทั้งหมด** ตอนแสดงผล เพื่อให้สีตามธีมของเว็บเสมอ
- เริ่มบทด้วย `<h1>` หนึ่งอัน แบ่งหัวข้อด้วย `<h2>` / `<h3>`
- กล่องเน้นข้อความ: `<div class="note">`, `<div class="tip">`, `<div class="warning">`

ดูตัวอย่างครบทุกองค์ประกอบได้ที่ `books/guide/03-showcase.html` (HTML) และ `books/guide/04-markdown-demo.md` (markdown)

## อัปโหลดขึ้นคลาวด์ (ไม่ต้องผ่าน git)

เมื่อ deploy บน Vercel แล้ว กดปุ่ม **＋** บนชั้นหนังสือจะเข้าหน้า `upload.html` — เลือกไฟล์ .md/.html หรือวางเนื้อหา แล้วอัปโหลดเก็บใน **Vercel Blob** ได้จากทุกอุปกรณ์ หนังสือที่อัปโหลดจะขึ้นบนชั้นพร้อมป้าย ☁️ อ่านได้เหมือนหนังสือใน repo ทุกอย่าง

**ตั้งค่าครั้งแรก (ใน dashboard ของ Vercel):**

1. Storage → Create Database → **Blob** → เชื่อมกับโปรเจกต์นี้ (จะได้ env `BLOB_READ_WRITE_TOKEN` อัตโนมัติ)
2. Settings → Environment Variables → เพิ่ม `UPLOAD_KEY` = รหัสลับที่ตั้งเอง (ใครมี key นี้ = อัปโหลด/ลบได้)
3. Redeploy หนึ่งครั้ง

**การทำงาน:**

- อ่าน = สาธารณะ (ใครมีลิงก์ก็อ่านได้) / เขียน+ลบ = ต้องแนบ key (`Authorization: Bearer <UPLOAD_KEY>`)
- ใส่ key ครั้งแรกครั้งเดียวในหน้าอัปโหลด เบราว์เซอร์จะจำไว้ (localStorage ผูกกับโดเมนของเว็บ)
- เลือกไฟล์ .md **หลายไฟล์พร้อมกันได้** — ไฟล์ละบท เรียงตามชื่อไฟล์ หรือไฟล์เดียวแบ่งเป็นหลายบทตามหัวข้อ #/## ก็ได้
- แนบ**รูปประกอบ**ได้จากขั้นใส่เนื้อหา (ไม่เกิน 3MB/รูป) — อัปขึ้น Blob แล้วแทรกลิงก์ markdown ให้เอง
- **แก้ไขทีหลังได้**: ชื่อเล่ม/คำอธิบาย/ปกอีโมจิ/ชื่อบท จากปุ่ม ✏️ ในขั้นเลือกหนังสือ
- สารบัญคลาวด์เก็บเป็น JSON ใน Blob (เขียนแบบ versioned), เนื้อหาบทเก็บเป็นไฟล์ .md/.html ใน Blob
- API: `GET /api/books` (สารบัญ), `POST /api/books` (อัปโหลด/แก้บท), `PATCH /api/books` (แก้ข้อมูลเล่ม/ชื่อบท), `DELETE /api/books?bookId=..&file=..` (ลบบท ถ้าไม่ส่ง file = ลบทั้งเล่ม), `POST /api/images` (อัปโหลดรูป `{filename, dataBase64}`)

## ฟีเจอร์ของ reader

- ธีมสว่าง / ซีเปีย / มืด (ค่าเริ่มต้นตามระบบ)
- ปรับขนาดตัวอักษร 14–26px
- 🔤 เลือกฟอนต์ไทย/อังกฤษได้ 6 แบบ (ค่าเริ่มต้น, Sarabun, Krub, Thasadith, Playpen Sans Thai, Noto Serif Thai) — โหลดจาก Google Fonts เฉพาะตัวที่เลือก และมีผลทุกหน้าของเว็บ
- 🔍 ค้นหาข้อความข้ามทุกเล่มจากหน้าชั้นหนังสือ — กดผลค้นหาแล้วเปิดบทนั้นพร้อมไฮไลต์คำที่เจอ
- สีโค้ด (highlight.js), สูตรคณิต (KaTeX), แผนภาพ (mermaid) — โหลดเฉพาะบทที่ใช้จริง
- PWA: Add to Home Screen บนมือถือได้ และบท/หน้าที่เคยเปิดแล้วอ่านซ้ำได้แม้ออฟไลน์
- จำตำแหน่งอ่านล่าสุดของแต่ละบท + ปุ่ม "อ่านต่อ" ที่หน้าชั้นหนังสือ
- นับบทที่อ่านจบ (เลื่อนถึง 90%) แสดง ✓ ในสารบัญและ progress bar ที่หน้าชั้นหนังสือ
- ปุ่ม prev/next, สารบัญแบบ drawer, ลูกศร ← → บนคีย์บอร์ด
- **โหมดพลิกหน้าแบบ ebook reader** (ค่าเริ่มต้น): เนื้อหาแบ่งเป็นหน้าเต็มจอ (จอกว้างแสดง 2 คอลัมน์เหมือนหนังสือกางออก) พลิกด้วยการ**ปัด แตะซ้าย/ขวาของจอ ลูกศร หรือปุ่มล่างจอ** พร้อมอนิเมชันพลิกกระดาษ 3D สุดบทแล้วไหลข้ามบทให้เอง — สลับเป็น**โหมดเลื่อนแนวตั้ง**ได้จากปุ่ม 📄/📜 บน topbar และปิดอนิเมชันได้จากสวิตช์ท้ายสารบัญจากสวิตช์ท้ายสารบัญ
- เปลี่ยนบทไม่ reload หน้า (back/forward ของเบราว์เซอร์ยังใช้ได้ปกติ)
- ตารางกว้างเลื่อนแนวนอนในกรอบตัวเอง, รองรับ safe-area ของมือถือมีติ่ง

ข้อมูลการอ่านทั้งหมดเก็บใน localStorage ของแต่ละอุปกรณ์ ไม่มี backend
